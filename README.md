# PHP Dasar

PHP (Hypertext Preprocessor) adalah bahasa pemrograman yang berjalan di sisi server dan digunakan untuk membangun website dinamis. PHP memungkinkan halaman web menampilkan data yang berubah-ubah sesuai kondisi, seperti sistem login, pengolahan form, dan koneksi ke database.

Dengan PHP, website tidak hanya menampilkan informasi statis, tetapi dapat berinteraksi dengan pengguna dan menyimpan data.

## Catatan
PHP biasanya digunakan bersama:
- **HTML & CSS** untuk tampilan  
- **MySQL** untuk penyimpanan data  
- **JavaScript** untuk interaksi di sisi client

Memahami PHP dasar adalah langkah penting untuk menjadi web developer backend dan membangun aplikasi berbasis web yang dinamis.
